# Trigger Cases

用于人工检查 description 是否把完整求职流程与近邻任务分开。

## Should trigger

1. “我想找 AI 产品经理实习，从研究岗位要求开始，帮我做简历然后把能投的岗位排优先级。”
2. “给我跑一遍完整求职流程：先看这个行业大中小公司 JD，再用我的经历定简历，最后找当前岗位。”
3. “我不知道数据分析岗到底要什么能力，先看市场 JD，再结合我的项目做一版简历并找职位。”
4. “这是我的经历文件，我目标增长运营，帮我从岗位调研一直做到投递清单。”
5. “完整找工作，目标后端开发，校招，北京/上海都可以。”
6. “帮我从岗位研究、简历做到最后的投递看板，别让我漏投。”
7. “我想把找到的岗位持续跟踪，并可选同步到飞书。”

## Should not trigger

1. “把我这段简历 bullet 润色一下。”
2. “解释一下这个 JD 在说什么。”
3. “帮我模拟字节产品经理一面。”
4. “给我找 5 个 AI 产品经理岗位链接，不用改简历。”
5. “我适合做产品还是运营？聊聊职业方向。”

## Ambiguous / manual invocation acceptable

1. “帮我做 AI 产品经理简历。” → 默认是简历单任务，不强制完整流水线；用户明确要求完整流程或手动调用本 Skill 时才进入。
2. “帮我找工作。” → 先问目标岗位；若用户确实要端到端流程，则触发。
