# Small & High-Quality Company Discovery｜小而美企业发现与验证

本文件只负责 **Phase 1 企业树中的“小而美 / 早期优质企业”发现与验证**。它不是独立求职流程，也不负责简历、岗位匹配或投递。

## 1. Owns

在用户已经确定目标行业后，从低知名度中小企业里发现值得进入企业树的候选，并基于可追溯证据完成质量验证。

目标不是“找小公司”，而是找到：

> **规模相对较小，但业务真实、细分竞争力明确、存在成长信号，并且对目标岗位有实际价值的公司。**

发现信号只是线索：

```text
发现信号 ≠ 优质结论
```

任何公司都必须经过验证与 Quality Gate 后，才能进入企业树的“小而美”主名单。

## 2. Inputs

必需：
- 目标行业 / 细分赛道
- 目标岗位

按需获取，不要一次性向用户索取：
- 目标城市 / 地区
- 公司规模偏好
- 明确排除项
- 是否接受早期创业公司

若地区不会改变当前企业发现结果，不要为了形式主义追问。

## 3. Exclusions｜本模块不负责

不要在这里做：
- 判断用户本人是否适合某家公司；
- 针对用户经历计算具体岗位匹配分；
- 写简历或改简历；
- 查当前具体职位并完成 S/A/B 排序；
- 创建投递进度表；
- 直接投递或联系招聘方。

这些分别属于后续的简历、Phase 4 岗位匹配与 Phase 5 投递工作台。

## 4. Discovery｜候选企业发现

候选来源分为 4 类。根据行业选择最有区分度的来源，不要机械把所有渠道跑一遍。

### A. 官方资质 / 政府产业名单

适合发现合规性、产业地位或技术能力较强但大众知名度低的企业。

常见信号：
- 专精特新 / 专精特新“小巨人”；
- 高新技术企业；
- 瞪羚企业；
- 制造业单项冠军；
- 地方重点产业 / 示范企业；
- 官方独角兽 / 潜在独角兽名单。

优先政府、工信、科技、发改、园区等官方来源。第三方转载只做发现，不作为最终认证证据。

### B. 行业 / 区域榜单

适合发现细分赛道、本地市场或垂直业务里的低知名度强公司。

常见来源：
- 细分赛道 Top / 行业专项榜；
- 城市 / 地区百强；
- 民营企业百强；
- 行业协会名单；
- 产业园重点企业；
- 垂直领域龙头 / 标杆企业名单。

榜单本身只能证明“值得研究”，不能直接证明公司优质。

### C. 创投 / 产业资本数据库

适合互联网、AI、机器人、硬科技、新消费等资本密集型行业。

常见来源：
- IT桔子；
- 36氪项目 / 融资信息；
- 烯牛数据；
- 投中网；
- 知名 VC / CVC 官方 Portfolio；
- 地方产业基金投资名单。

融资只是一种成长信号，不等于模式成熟，更不等于值得求职。

### D. 行业专属来源

根据目标行业动态补充最有解释力的来源：

| 行业 | 优先补充来源 |
|---|---|
| AI / 互联网 | AI 企业榜、创投数据库、产业园、代表产品 / 开发者生态 |
| 制造 / 工业 | 专精特新、小巨人、单项冠军、供应链地位、产业集群 |
| 游戏 | 产品榜单、版号 / 产品发行记录、研发与发行能力、招聘活跃度 |
| 电商 / 跨境 | 品牌 / 平台榜、跨境电商榜、上市 / 融资、供应链与品牌能力 |
| 机器人 | 量产 / 交付、客户案例、机器人产业榜、融资、场景落地 |
| 生物医药 | 管线阶段、临床进展、专利 / 技术平台、产业园、专业投资机构 |
| 文创 / 设计 / 传媒 | 专业奖项、行业榜单、标杆客户、地方文化产业名录 |

若行业不在表中，先判断什么证据最能证明该行业的“业务真实 + 细分竞争力”，再选择来源。

## 5. Validation｜候选企业验证

进入候选池后，统一验证以下维度：

### 5.1 当前主营业务

确认：
- 公司现在主要做什么；
- 目标行业是否仍是核心业务；
- 是否存在真实产品 / 服务 / 客户场景。

不要只依赖融资新闻里的旧业务描述。

### 5.2 公司规模

规模用于描述，不用于单独判断质量。

记录可验证的区间即可，例如：
- `<100`；
- `100–500`；
- `500–1000`；
- `1000+`；
- `Unknown`。

“员工少”不能自动降级，“员工多”也不能自动升级。

### 5.3 业务质量

可接受证据包括：
- 当前产品 / 服务持续运营；
- 公开客户案例；
- 明确商业化路径；
- 用户 / 客户规模；
- 量产 / 交付 / 上线记录；
- 可验证收入、订单或市场采用信号。

### 5.4 细分行业地位

可接受证据包括：
- 权威行业榜单；
- 细分市占 / 排名；
- 标杆客户；
- 头部供应链位置；
- 代表性产品；
- 行业协会 / 官方产业认定。

### 5.5 成长信号

优先看近期：
- 新融资；
- 新产品 / 新业务；
- 客户增长 / 市场扩张；
- 招聘扩张；
- 新区域 / 海外扩张；
- 产能 / 交付扩大。

### 5.6 外部背书

例如：
- 有效官方资质；
- 知名 VC / CVC / 产业基金；
- 权威行业榜单；
- 标杆客户；
- 上市公司 / 大型集团战略合作。

外部背书是加分项，不是业务质量替代品。

### 5.7 目标岗位价值

这是求职场景必须保留的维度：
- 目标岗位是否与核心业务直接相关；
- 是否存在真实产品 / 业务问题可做；
- 公司是否有对应职能或招聘记录；
- 该岗位是否可能获得比“大公司螺丝钉”更完整的业务 ownership。

不得仅凭“创业公司一般能做得更多”这种想象打高分。

## 6. Evidence Status｜证据状态

每个关键判断必须标记证据状态：

- `Verified`：有直接、可靠来源支持；
- `Likely`：有多条间接证据，但缺直接确认；
- `Unknown`：目前没有足够证据；
- `Conflicting`：来源互相冲突，需要继续核验。

缺证据时写 `Unknown`，不要为了填满表格补事实。

## 7. Freshness｜时效规则

成长性证据必须区分时效：

- 近 12 个月：强当前信号；
- 12–36 个月：辅助信号；
- 超过 36 个月：历史背景，不得作为主要当前成长证据。

官方资质同样区分：
- 当前有效；
- 历史获得；
- 无法确认。

例如“2022 年完成 B 轮”在 2026 年只能算历史融资背景，不能单独证明当前仍高速成长。

## 8. Quality Gate｜小而美质量门槛

内部使用 5 个维度辅助比较：

| 维度 | 权重 | 判断重点 |
|---|---:|---|
| 业务质量 | 25 | 产品 / 服务是否真实持续、商业模式和客户场景 |
| 细分行业地位 | 25 | 是否在某个垂直领域具备可验证竞争力 |
| 成长信号 | 20 | 近期融资、扩张、产品、客户、招聘等 |
| 外部背书 | 15 | 官方资质、资本、榜单、标杆客户 |
| 目标岗位价值 | 15 | 目标岗位与核心业务关联度、工作空间 |

参考解释：
- `70–100`：小而美重点企业；
- `50–69`：候选，证据或质量仍需补充；
- `<50`：不进入企业树主名单。

### 评分纪律

- 分数是排序辅助，不是假装精确的“公司投资评级”；
- `Unknown` 维度不得凭印象给高分；
- 单一强信号不能代替其他维度；
- 高分但证据置信度低时，不得直接列为重点企业。

同时输出 `Evidence Confidence`：
- `High`：关键结论大多为 Verified，且来源互相一致；
- `Medium`：核心结论基本成立，但仍有若干 Likely / Unknown；
- `Low`：关键信息缺失、过期或互相冲突。

## 9. 禁止单信号升级

以下任一条件 **单独出现** 时，只能进入候选池，不得直接判为“小而美”：

- 专精特新 / 高新技术企业；
- 完成融资；
- 被某媒体报道；
- 出现在某个榜单；
- 员工人数较少；
- 有知名投资机构；
- 官网写着“行业领先”。

至少要形成“业务质量 + 细分竞争力 + 岗位价值”的组合证据。

## 10. Output Contract｜输出格式

每家进入企业树的小而美企业至少记录：

```text
公司名称：
行业 / 细分赛道：
城市 / 地区：
规模区间：

发现渠道：
当前主营业务：
业务质量证据：
细分行业地位证据：
成长信号：
外部背书：
目标岗位价值：

Quality Score：
Evidence Confidence：High / Medium / Low
证据状态：Verified / Likely / Unknown / Conflicting

官网：
官方招聘入口：
验证日期：
为什么纳入：
风险 / 缺失信息：
```

最终进入 `企业树.md` 时，保留结论和关键证据，不必把完整调研过程全部塞进去。

## 11. Integration with JobHuntBot

Phase 1：

```text
目标岗位 + 已确认行业
→ 发现小而美候选
→ 验证
→ Quality Gate
→ 写入企业树“小而美”分支
```

Phase 4：

```text
读取企业树
→ 根据招聘类型进入这些公司的官方招聘渠道
→ 查当前真实岗位
→ Hard Gate
→ Match Score
→ S / A / B / blocked
```

本模块只回答“哪些公司值得进入企业树”，Phase 4 才回答“它现在有没有值得用户投的具体岗位”。

## 12. Failure Rules

出现以下情况时不要硬凑结果：
- 行业太小，候选数量不足；
- 大部分证据为多年以前；
- 公司已经明显转型离开目标行业；
- 公司官网 / 业务状态无法确认；
- 质量证据与负面经营信号明显冲突。

此时明确写：`证据不足`、`需复核` 或 `不进入主名单`。
