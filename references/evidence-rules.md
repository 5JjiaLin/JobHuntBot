# Evidence Rules｜真实性、边界与中断规则

这些规则跨 4 个阶段生效，优先级高于“让结果更好看”。

## 1. 不得自行补全

禁止编造：
- 用户经历、职责、技能、证书
- 精确数字、准确率、用户量、A/B Test
- 岗位、岗位 ID、URL、截止日期、招聘状态
- 因果关系、动机、公司梯队事实

材料没有支持，就写“未确认 / 无证据 / 当前未找到”。

## 2. 四个常见归因错误

- `Demo` 不得写成 `上线`
- `团队结果` 不得自动写成 `个人结果`
- `AI / 工具生成` 不得自动写成 `用户本人设计/实现`
- `当前复盘` 不得倒灌成 `当时判断`

## 3. 证据强度不等于文字强度

弱证据必须保留边界。为了命中 JD 改几个动词，不会让证据凭空升级。

遇到能力缺口：
- 明确指出
- 判断是否是 Hard Gate
- 决定弱化、暂不写、或进入 blocked

不要“关键词补齐”。

## 4. 当前网页证据

岗位研究与最终投递属于时效信息：
- 记录验证时间
- 只有实际打开正文才写“已验证 JD”
- 页面失效、需登录、地区跳转、职位下线都如实标记
- 第三方页面可以做发现线索，但未获官网确认不得升级为官方岗位

## 5. Hard Gate 先于匹配分

以下情况先判断资格，不先算分：
- 求职类型不符
- 毕业年份 / 年级明确不符
- 法定/资格证硬要求不符
- 明确工作年限不符
- 明确语言/专业/技术硬门槛不符且无等价证据
- 地域或工作授权存在明确不可满足限制

Hard Gate 不满足 → `blocked`。不能靠“其他能力很强”把 90 分算回来。

## 6. 隐私与敏感材料

经历材料中出现客户、患者、公司未公开数据、账号、密钥、内部链接等，不要求用户暴露更多。输出简历时做必要抽象化，不泄露敏感细节。

## 7. 中断策略

### JD 不足
继续换同义岗位词、其他公司、官方历史页或可靠完整第三方 JD。仍不足时明确“样本有限”，降低结论强度。

### 无经历文件
进入 Gate B，提供经历深挖 Prompt，暂停简历。

### Core 能力没有经历证据
保留为空白能力，不编；在简历审计和岗位匹配风险中体现。

### 简历审计失败
先修简历或补事实，不进入最终岗位搜索。

### 官方职位打不开
标记 B 类登录入口 / 页面失效 / 待复核，不制造直链。

### 第三方发现、官网未找到
只能进 `blocked / 待官网复核`，不能进正式 S/A/B。

## 8. 停止条件

不要因为“还能继续搜”无限扩张任务。

阶段完成后停止：
- 阶段 1：能力模型已稳定且证据足够
- 阶段 2：核心经历事实闭环足够写简历
- 阶段 3：简历通过审计
- 阶段 4：公司池已合理覆盖、正式候选均完成验证或明确阻塞

任务目标是可执行求职闭环，不是穷举整个互联网招聘市场。
